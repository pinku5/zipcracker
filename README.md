# zipcracker

ZipCracker is a Python-based ZIP password recovery tool that tests passwords from a user-provided wordlist against encrypted ZIP archives.

It is designed for educational purposes, security research, and recovering access to ZIP files when you have authorization to do so.

Features
.Fast wordlist-based password testing
.Simple command-line interface
.Lightweight and easy to use
.Supports custom wordlists
.Progress display during testing
.Open-source and customizable
